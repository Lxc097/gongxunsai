# 工训赛智能搬运车核心代码

从当前开发项目整理的比赛功能代码，分为两个目录：

| 目录 | 内容 |
| --- | --- |
| `visual/` | Jetson 感知、定位、导航、任务状态机，路径规划与通信协议，OpenMV 末端视觉 |
| `driver/` | STM32F407 主工程、底盘与执行器驱动、HAL/CMSIS/FreeRTOS 编译依赖 |

排除了单元测试、台架测试、传感器检查脚本、维护固件、历史 F103/2025 工程、日志、缓存、编译产物、手册与无关素材。

## 当前状态

这是当前开发代码快照。Jetson 主入口目前实现单站导航；完整两轮搬运状态机尚未接入全部实物采集线程及机械臂适配器。F407 保留当前默认的导航隔离和电机验收门控。代码整理不代表整车赛程已经联调完成。

运行与编译方法分别见 [visual](visual/README.md) 和 [driver](driver/README.md)。
